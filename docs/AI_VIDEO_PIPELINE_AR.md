# خط إنتاج الفيديو بالذكاء الاصطناعي في CUTO

## قرار المنتج

CUTO لا يستخدم لقطات طبخ جاهزة أو مكتبات stock footage. كل مشهد مرئي في الفيديو النهائي يجب أن يكون مولدًا بالذكاء الاصطناعي خصيصًا للمشروع، ثم يتم تجميع المشاهد ومونتاجها وإضافة الصوت والترجمة والهوية البصرية.

## توضيح مهم بشأن Google Flow

Google Flow هو منتج لصناعة الفيديو يعمل عبر واجهته، وليس من الصحيح افتراض وجود مفتاح API عام لـ Flow يمكن للتطبيق استدعاؤه مباشرة. لتشغيل توليد الفيديو برمجيًا من CUTO، نستخدم واجهة Google Gemini API مع نموذج Veo المتاح للحساب، وفق وثائق Google الرسمية:
- Flow: https://labs.google/fx/tools/flow
- Veo API: https://ai.google.dev/gemini-api/docs/veo

لا تستخدم أتمتة متصفح غير رسمية لحساب Flow أو تطلب من المستخدم مشاركة كلمة مرور Google. إذا أراد المستخدم استخدام واجهة Flow نفسها، يكون ذلك سير عمل منفصلًا يتطلب عملًا يدويًا، وليس backend API مضمونًا.

## خط الإنتاج المطلوب

1. **تحليل القناة والفكرة:** استخدم إعدادات القناة المحفوظة (اللغة، اللهجة، نوع الصوت، النيش، الجمهور، الأسلوب) لإنشاء موجز إنتاج واضح.
2. **السيناريو والوصفة:** ولّد خطوات ومقادير منظمة، ثم راجع اتساق الخطوات. لا تخترع كميات أو تعليمات سلامة غذائية عند غياب المعلومات.
3. **خطة مشاهد مولدة:** قسّم الفيديو إلى لقطات قصيرة، ولكل لقطة prompt مستقل يحدد الفعل، زاوية الكاميرا، الإضاءة، الأدوات، المكونات، شكل الطعام والاستمرارية البصرية. لا تضع كتابة مهمة داخل الفيديو المولد؛ أضف النصوص لاحقًا في مرحلة المونتاج لتجنب أخطاء الحروف.
4. **مرجع بصري ثابت:** أنشئ أو استخرج صور مرجعية مولدة للطبق والمكونات والأدوات، واستخدمها كإطارات أو مراجع حيث يدعم نموذج Veo ذلك، للمساعدة في الحفاظ على الاتساق بين المشاهد.
5. **توليد كل مشهد بواسطة Veo:** استدعِ Gemini API من Edge Function أو worker موثوق باستخدام GEMINI_API_KEY المحفوظ كسر في الخادم. راقب حالة كل عملية توليد وفق نمط العملية الفعلي في وثائق API، وتحقق من حالة الانتهاء قبل تنزيل الناتج.
6. **الصوت:** ولّد التعليق الصوتي منفصلًا باستخدام Gemini TTS أو خدمة صوت مناسبة، مع نوع الصوت واللغة واللهجة المختارة في إعدادات القناة. لا تفترض أن الصوت المولد داخل مشهد Veo سيطابق دائمًا تعليقًا مصريًا طويلًا ومتزامنًا.
7. **المونتاج:** اجمع فقط المقاطع المولدة بالذكاء الاصطناعي، ونسّقها إلى 9:16، ووازن الصوت، وأضف الترجمة واسم القناة و@username باللون الأبيض ضمن منطقة آمنة أسفل الفيديو.
8. **التصدير والتخزين:** استخدم FFmpeg في worker معزول أو خدمة رندر مناسبة لتصدير MP4، ثم ارفع الناتج إلى Supabase Storage الخاص. لا تعرض رابط التنزيل قبل اكتمال الرفع والتحقق.
9. **التقدم الحقيقي:** خزّن مراحل المهمة في قاعدة البيانات، مثل queued, planning, generating_scenes, generating_voice, rendering, uploading, completed, failed. تُحدّث النسبة بناء على أحداث فعلية من worker، لا على مؤقت في الواجهة.
10. **إعادة المحاولة والتكلفة:** استخدم مفاتيح idempotency، وحدود التزامن، والمهل الزمنية، وسياسة إعادة المحاولة، وحدود تكلفة/رصيد لكل حساب. لا تكرر توليد المشاهد تلقائيًا بلا حد.

## متطلبات زمن الخمس دقائق

خمس دقائق هدف أداء وليس ضمانًا. توليد عدة مشاهد منفصلة عبر نموذج فيديو قد يتجاوز ذلك بسبب طوابير المزود، والمدة، والدقة، وعدد المشاهد. يجب:
- بدء قياس وقت حقيقي من إرسال الطلب حتى جاهزية MP4.
- إظهار مراحل التقدم والوقت المنقضي، وعدم إظهار 100% قبل انتهاء الرندر والرفع.
- توفير إلغاء أو إعادة محاولة واضحة عند الفشل.
- لا تقصّر الوصفة أو تعرض لقطات غير مطابقة فقط لإخفاء التأخير.
- لا تعلن عن ضمان خمس دقائق حتى تنجح اختبارات الأداء على عينات واقعية وبعدد مشاهد مستهدف محدد.

## الأسرار المطلوبة

- `GEMINI_API_KEY`: سر خادم داخل Supabase Edge Functions Secrets أو مدير أسرار worker. يُستخدم للوصول إلى Gemini/Veo/TTS حسب المنتجات والصلاحيات المتاحة.
- لا يوجد `GOOGLE_FLOW_API_KEY` موثوق لمجرد أن المستخدم لديه وصول إلى Flow. لا تطلب هذا الاسم ولا تحاول استخدام بيانات دخول Flow.
- Supabase URL والمفتاح publishable للواجهة فقط؛ لا تضع `service_role` أو أي مفاتيح AI في متغيرات `VITE_*`.

## معايير القبول

- لا يوجد أي مصدر stock footage في خط الإنتاج.
- كل مشهد في المشروع مرتبط بمعرّف توليد AI وحالة ومرجع prompt.
- لا يُعرض أي فيديو مكتمل حتى يؤكد worker وجود ملف MP4 صالح.
- يظل نوع الصوت واللغة واللهجة وهوية القناة افتراضية لكل مشروع، مع السماح بالتعديل.
- حد قناتين لكل حساب يُفرض على الخادم/قاعدة البيانات.
- اختبار استمرارية شكل الطبق والمكونات بين المشاهد، وجودة الصوت، وترجمة عربية مقروءة، و9:16.
- توثيق زمن التوليد والتكلفة الحقيقية قبل تحديد خطة أسعار أو وعد خمس دقائق.
